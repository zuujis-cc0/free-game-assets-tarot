# Tarot artwork: Zuujis free game assets

478 Tarot card images, including alternate designs and the RWS deck in two resolutions. Public-domain **CC0**: use them in commercial or personal games. Credit is optional.

Every file is here on its own: open one on GitHub and use **Download raw file** to save just that file. Or download the whole pack:

**[Download zuujis-tarot-art.zip](https://github.com/zuujis-cc0/free-game-assets/releases/download/v1.0.0/zuujis-tarot-art.zip)** · [Preview gallery](https://github.com/zuujis-cc0/free-game-assets/blob/main/previews/tarot/README.md) · [All Zuujis packs](https://github.com/zuujis-cc0/free-game-assets)
